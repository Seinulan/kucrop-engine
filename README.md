# KUCrop Engine

Веб-версия AquaCrop для Полтавки (СКО): физическая модель урожая плюс ИИ-суррогат.

- **Физика:** AquaCrop-OSPy 3.1.0, Python-реализация методики ФАО AquaCrop. Все параметры читаются из ваших файлов настольного AquaCrop.
- **ИИ:** ExtraTrees, обученный на 1440 расчётах этой физики. Экспортирован в ONNX и выполняется прямо в Node.js за миллисекунды.

## Запуск

```bash
pip install -r requirements-train.txt   # aquacrop==3.1.0, numpy, pandas, scikit-learn, onnxruntime
npm install

python selfcheck.py                     # 1. все строки должны быть [OK]
python run_aquacrop.py --inspect        # что прочитано из файлов AquaCrop
python generate_model.py                # 2. (по желанию) переобучить ИИ, ~6 мин; готовая модель уже в репозитории
node server.js                          # 3. http://localhost:3000
```

Если Python вызывается иначе: `PYTHON_BIN=python node server.js`. Docker: `docker build -t kucrop . && docker run -p 3000:3000 kucrop`.

## Файлы

| Файл | Назначение |
|---|---|
| `aquacrop_files.py` | чтение `.CRO .SOL .GWT .MAN .CLI .Tnx .ETo .PLU` (формат AquaCrop 7.x) |
| `kucrop_core.py` | сборка модели AquaCrop из файлов и один расчёт `simulate()` для сайта и для обучения |
| `run_aquacrop.py` | вызывается сервером; `--config` (справочники), `--inspect` (диагностика) |
| `generate_model.py` | обучение ИИ: `aquacrop_model.onnx`, `model_meta.json`, `training_data.csv` |
| `onnx_export.py` | экспорт в ONNX: через skl2onnx, если он установлен, иначе встроенный; результат сверяется с sklearn |
| `selfcheck.py` | проверяет, что физика реально реагирует на каждый параметр |
| `server.js` | Express: `POST /api/predict` (физика и ИИ параллельно), `GET /api/config` |
| `public/index.html` | интерфейс |

Используются ваши данные: `final.CRO` (подсолнечник), `Wheat.CRO`, `Barley.CRO`, `Poltavka_NKA.SOL`, `Poltavka_0712.GWT`, `final_2.MAN`, `Poltavka.CLI` и погода за 2021–2024 годы.

## Проверка

- **Чтение файлов.** `Wheat.CRO` и `Barley.CRO` совпали со встроенными культурами ФАО в пакете по всем 66 параметрам. CRa/CRb почвы совпадают с формулой ФАО.
- **`selfcheck.py`: 11 из 11 проверок.** Подсолнечник 2024 при грунтовых водах 1.2 м даёт 2.78 т/га и 42.8 мм капиллярного подъёма, при 10 м даёт 2.48 т/га и 0 мм. Год 2021 даёт 0.42 т/га, 2024 даёт 2.52 т/га. Выполняется равенство «урожай = биомасса × HI».
- **ИИ (ExtraTrees, 1440 расчётов, отложенные 20%):** R² = 0.971, RMSE = 0.41 т/га.
  - подсолнечник: RMSE = 0.10 т/га
  - ячмень: RMSE = 0.06 т/га
  - пшеница: RMSE = 0.71 т/га
  - кросс-валидация: R² = 0.976
- **ONNX против sklearn:** расхождение не больше 2.4e-5.

## Ограничения (важно для защиты)

1. **ИИ не прогнозирует новые годы.** В признаках нет погоды, только год. Если исключить один год из обучения, качество падает: для 2021 R² ≈ 0, для остальных лет R² = 0.56–0.83. ИИ здесь быстрая замена физики для уже известной погоды 2021–2024, а не прогноз будущего урожая. Все метрики лежат в `model_meta.json`.
2. **`Wheat.CRO` — стандартная озимая пшеница ФАО** (Valenzano, Италия; цикл 197 дней). Это не яровая пшеница на 100 дней. При весеннем посеве цветение приходится на осень, и холод срывает опыление: посев в апреле даёт до 10 т/га при орошении, посев в середине июня даёт 0. Для реалистичной яровой пшеницы откалибруйте `.CRO` в настольном AquaCrop, положите его вместо `Wheat.CRO` и запустите `python generate_model.py`.
3. **Что движок OSPy не моделирует:** стресс плодородия 15% и сорняки из `final_2.MAN`, засолённость ECw = 0.9 из `.GWT`. Поэтому урожай может быть выше, чем в настольном AquaCrop. Сайт показывает это во вкладке Environment.
4. **`Poltavka_0712.GWT`:** в заголовке написано «1.70 m», а в данных 1.90 м. Используется значение из данных (1.90 м). Если правильно 1.70, исправьте строку данных.
5. «Орошение» — это сценарий (поддержание влажности ≥ 70% доступной воды), его нет в ваших файлах. Почвы Loam и SandyLoam — встроенные профили для сравнения.
