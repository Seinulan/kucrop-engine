# KUCrop Engine

Веб-версия AquaCrop для Северо-Казахстанской области (СКО), Казахстан. Целевой год — **2024**.

- **Физика:** AquaCrop-OSPy 3.1.0, Python-реализация методики ФАО AquaCrop. Расчёт собирается из файлов AquaCrop, как в настольной программе.
- **ИИ:** ExtraTrees, обученный на расчётах этой физики для 2024 года. Экспортирован в ONNX и выполняется в Node.js примерно за 0.01 мс, тогда как физике нужно около 0.2 с.

## Запуск

```bash
pip install -r requirements-train.txt   # aquacrop==3.1.0, numpy, pandas, scikit-learn, onnxruntime
npm install

python selfcheck.py                     # 1. все строки [OK]
python run_aquacrop.py --inspect        # все файлы AquaCrop в проекте и что из них прочитано
node server.js                          # 2. http://localhost:3000
python generate_model.py                # (по желанию) переобучить ИИ из консоли, ~7 мин
```

Если Python вызывается иначе: `PYTHON_BIN=python node server.js`. Docker: `docker build -t kucrop . && docker run -p 3000:3000 kucrop`.

## Файлы AquaCrop в интерфейсе

Вверху страницы панель «Файлы проекта». Для каждого типа файла: выпадающий список, кнопки **Править**, **＋** (новый файл), **Загрузить**, **Скачать**, **✕** (удалить свой файл) и сводка параметров.

| Слот | Файлы | Что поддерживается |
|---|---|---|
| Климат | `.CLI` + `.Tnx` `.ETo` `.PLU` | суточные ряды, привязанные к году; нужен 2024 год |
| Культура | `.CRO` | цикл в календарных днях или в градусо-днях (GDD) |
| Почва | `.SOL` | любое число горизонтов, CRa/CRb из файла; плюс встроенные Loam/SandyLoam для сравнения |
| Грунтовые воды | `.GWT` | нет / постоянный уровень (глубину можно изменить) / переменный уровень |
| Управление | `.MAN` | мульча, валики; плодородие и сорняки движок не моделирует (показывается) |

Встроенные файлы лежат в корне проекта, свои — в `user_files/` (папка в `.gitignore`). Файл, который положили в папку вручную, появляется в списке сам.

### Редактор файлов

Кнопка **Править** открывает окно с тремя вкладками:

- **Форма.** Поля с русскими подписями и единицами (для `.CRO` — фенология, температуры, крона, корни, водный стресс, продуктивность; для `.SOL` — таблица горизонтов; для `.GWT` — режим и уровень; для `.MAN` — мульча, валики и др.). Под основными полями спрятан список всех параметров файла с поиском. Изменённые поля подсвечиваются, у каждого есть кнопка «↺».
- **Текст.** Исходный текст файла. Сюда можно вставить файл целиком (кнопка «Вставить из буфера» или Ctrl+V). Так же правятся `.CLI`, `.Tnx`, `.ETo`, `.PLU`.
- **Изменения.** Построчное сравнение с исходным файлом.

Любая правка проверяется на сервере почти сразу (то же чтение, что при расчёте): внизу окна зелёная сводка или красная ошибка с номером строки. Например, `CCx = 1.7` или `FC > SAT` не дадут сохранить файл. Проверки значений: Tbase < Tupp, 0 < CCx ≤ 1, WP* > 0, 0 ≤ HI0 ≤ 100 %, Zmin ≤ Zmax, пороги p в диапазоне 0–1, цветение и старение не позже созревания, у почвы 0 < WP < FC < SAT.

Встроенные файлы не перезаписываются: правка сохраняется как копия в `user_files/` (по умолчанию `имя_my.расширение`). Кнопка **Скачать** отдаёт файл с правками в формате AquaCrop (Windows-кодировка, переводы строк CRLF), его можно открыть в настольной программе. В файлах допустимы только латиница, цифры и знаки.

Чтобы изменить погоду: в редакторе климата выберите в списке `.Tnx` / `.ETo` / `.PLU`, сохраните копии под новыми именами, затем в копии `.CLI` укажите эти имена.

### ИИ и ваши файлы

ИИ обучен на содержимом файлов `Poltavka.CLI`, `final/Wheat/Barley.CRO`, `Poltavka_NKA.SOL` (а также Loam и SandyLoam), `final_2.MAN` и постоянном уровне грунтовых вод. Совпадение проверяется по содержимому файлов (sha256), а не по имени: у каждого файла в списке есть пометка «ИИ ✓». Если выбран другой или изменённый файл, сайт показывает только физику и объясняет почему.

Блок **«ИИ-суррогат»** на странице показывает, какие выбранные файлы ИИ не знает, и кнопкой **«Переобучить ИИ на выбранных файлах…»** запускает обучение прямо с сайта: отметьте культуры и почвы, выберите точность (400, 1000 или 1800 расчётов, примерно 2–8 минут). Обучение идёт в фоне с индикатором хода; новая модель (`aquacrop_model.onnx`, `model_meta.json`, `training_data.csv`) подменяет прежнюю только после успешной проверки ONNX против sklearn. Исходную модель всегда можно вернуть командой `git checkout aquacrop_model.onnx model_meta.json training_data.csv`.

## Результаты

Урожай физики и ИИ, водный баланс, кроны и транспирация, осадки и капиллярный подъём, продуктивность, вкладка **«Климат 2024»**: осадки и ETo по месяцам в сравнении со средним других лет ряда, температуры и осадки по дням вегетации. Выгрузка: **CSV по дням** (открывается в русском Excel: разделитель `;`, десятичная запятая) и **Печать / PDF** (светлый отчёт со всеми вкладками и списком использованных файлов).

## Проверка (AquaCrop 3.1.0)

- `Wheat.CRO` и `Barley.CRO` совпали со встроенными культурами ФАО в пакете по всем 66 параметрам. Культура в градусо-днях согласуется с вариантом в календарных днях: ячмень созревает за 96 дней против 93.
- **Подсолнечник 2024:** грунтовые воды на 1.2 м: 2.78 т/га (капиллярный подъём 43 мм); на 10 м и без грунтовых вод: 2.48 т/га.
- **ИИ, отложенные 20%:** R² = 0.9986, RMSE = 0.10 т/га. По глубине грунтовых вод от 1 до 10 м ИИ отклоняется от физики не больше чем на 0.10 т/га.
- **Редактор:** правка WP* в `.CRO` с 17 до 19 меняет расчёт (2.52 → 2.82 т/га); после переобучения на копии ИИ даёт 2.77 т/га.

## Исправлено по сравнению с первой версией

- Параметры культур не применялись: движок молча отбрасывал незнакомые имена.
- Грунтовые воды были выключены (`water_table='Constant'` вместо `'Y'`).
- Водный баланс, биомасса и HI были константами-заглушками, график кроны состоял из нулей, пшеница падала с ошибкой, погода 2021 года шла под видом 2024-го.
- Начальная влажность задавалась только для верхнего горизонта; теперь для каждого горизонта.

## Ограничения (важно для защиты)

1. **ИИ воспроизводит физику для 2024 года и файлов обучения.** Прогнозом урожая на другие годы он не является.
2. **`Wheat.CRO` — стандартная озимая пшеница ФАО** (Италия, 197 дней). Для яровой пшеницы СКО загрузите откалиброванный `.CRO` (или поправьте этот в редакторе) и переобучите ИИ.
3. **Чего движок OSPy не моделирует:** плодородие 15% и сорняки из `.MAN`, засолённость из `.GWT`. Поэтому урожай может быть выше, чем в настольном AquaCrop. Правка этих полей в редакторе на расчёт не влияет.
4. **`Poltavka_0712.GWT`:** в заголовке написано 1.70 м, а в данных 1.90 м. Используются данные; интерфейс подсвечивает это расхождение.
5. **Старт с влажностью WP** во всём профиле — крайний сценарий: по алгоритму ФАО сухая почва не проводит капиллярный подъём, поэтому урожай близок к нулю.
6. **Переобучение ИИ** работает только с постоянным уровнем грунтовых вод и климатом, в котором есть 2024 год.
