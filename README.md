KUCrop Engine

Веб-версия AquaCrop для Северо-Казахстанской области (СКО), Казахстан. Целевой год — 2024.

Физика: AquaCrop-OSPy 3.1.0, Python-реализация методики ФАО AquaCrop. Расчёт собирается из файлов AquaCrop, как в настольной программе.
ИИ: ExtraTrees, обученный на 1800 расчётах этой физики для 2024 года. Экспортирован в ONNX и выполняется в Node.js примерно за 0.01 мс, тогда как физике нужно около 0.2 с.

Запуск

```bash
pip install -r requirements-train.txt    aquacrop==3.1.0, numpy, pandas, scikit-learn, onnxruntime
npm install

python selfcheck.py                      1. все строки [OK]
python run_aquacrop.py --inspect         все файлы AquaCrop в проекте и что из них прочитано
node server.js                           2. http://localhost:3000
python generate_model.py                 *по желанию, переобучить ИИ, ~7 мин
```

Интерфейс

SaaS-приложение: боковое меню, верхняя панель, отдельные страницы.

- Обзор — главные числа сезона (урожай AquaCrop и ИИ в т/га и ц/га, осадки, подъём от грунтовых вод), карточка урожая с «полосой сезона» (покрытие кроны по дням от посева до уборки), график кроны, сценарий расчёта.
- Симуляция — выбор файлов и условий (дата посева, глубина грунтовых вод, орошение, начальная влажность), результат и вкладки: крона, осадки, водный баланс, урожай, условия расчёта.
- Файлы AquaCrop — все .CLI/.CRO/.SOL/.GWT/.MAN и ряды погоды: выбрать, загрузить (можно перетащить), скачать, удалить свои.
- ИИ-модель — точность (R², RMSE, по культурам), скорость против физики, важность признаков, файлы обучения, ограничения.
- Настройки — тема и язык; раздел «Аккаунт» (вход появится позже).

Светлая и тёмная тема (плавный переход от кнопки, по умолчанию — как в системе). Языки RU / KZ / EN: переводится весь интерфейс и сообщения сервера (сводки файлов, ошибки, условия расчёта, причины, почему ИИ не показан). Выбор темы, языка, файлов и параметров запоминается в браузере.

Вход и база данных — следующий шаг. Сейчас все работают как «Гость»; в меню и настройках уже есть место под профиль, а сервер передаёт язык и параметры так, что добавить SQLite, вход и историю расчётов можно без переделки страниц.

Код: `i18n.py` — тексты сервера на трёх языках; `public/js/i18n.js` — тексты интерфейса; `public/js/app.js` — состояние, запросы, тема, язык, маршруты; `public/js/pages.js` — страницы; `public/js/charts.js` — графики; `public/css/app.css` — стили и обе темы. Сборка не нужна.

Ограничения

1. ИИ воспроизводит физику для 2024 года и файлов обучения. Прогнозом урожая на другие годы он не является.
2. `Wheat.CRO` - стандартная озимая пшеница ФАО** (Италия, 197 дней). Для яровой пшеницы СКО загрузите откалиброванный `.CRO`.
3. Чего движок OSPy не моделирует: плодородие 15% и сорняки из `.MAN`, засолённость из `.GWT`. Поэтому урожай может быть выше, чем в настольном AquaCrop.
4. `Poltavka_0712.GWT`: в заголовке написано 1.70 м, а в данных 1.90 м. Используются данные; интерфейс подсвечивает это расхождение.
5. Старт с влажностью WP во всём профиле - крайний сценарий: по алгоритму ФАО сухая почва не проводит капиллярный подъём, поэтому урожай близок к нулю.
