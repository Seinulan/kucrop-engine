# KUCrop Engine

Веб-версия AquaCrop для Северо-Казахстанской области (СКО), Казахстан. Целевой год — **2024**.

- **Физика:** AquaCrop-OSPy 3.1.0, Python-реализация методики ФАО AquaCrop. Расчёт собирается из файлов AquaCrop, как в настольной программе.
- **ИИ:** ExtraTrees, обученный на 1800 расчётах этой физики для 2024 года. Экспортирован в ONNX и выполняется в Node.js примерно за 0.01 мс, тогда как физике нужно около 0.2 с.

## Запуск

```bash
pip install -r requirements-train.txt   # aquacrop==3.1.0, numpy, pandas, scikit-learn, onnxruntime
npm install

python selfcheck.py                     # 1. все строки [OK]
python run_aquacrop.py --inspect        # все файлы AquaCrop в проекте и что из них прочитано
node server.js                          # 2. http://localhost:3000
python generate_model.py                # (по желанию) переобучить ИИ, ~7 мин; готовая модель уже есть
```

Если Python вызывается иначе: `PYTHON_BIN=python node server.js`. Docker: `docker build -t kucrop . && docker run -p 3000:3000 kucrop`.

## Файлы AquaCrop в интерфейсе

Вверху страницы панель «Файлы проекта». Для каждого типа файла есть выпадающий список, кнопки **Загрузить**, **Скачать** и **✕** (удалить свой файл), а также сводка параметров.

| Слот | Файлы | Что поддерживается |
|---|---|---|
| Климат | `.CLI` + `.Tnx` `.ETo` `.PLU` | суточные ряды, привязанные к году; нужен 2024 год. Загружайте все 4 файла разом |
| Культура | `.CRO` | цикл в календарных днях или в градусо-днях (GDD) |
| Почва | `.SOL` | любое число горизонтов, CRa/CRb из файла; плюс встроенные Loam/SandyLoam для сравнения |
| Грунтовые воды | `.GWT` | нет / постоянный уровень (глубину можно изменить) / переменный уровень |
| Управление | `.MAN` | мульча, валики; плодородие и сорняки движок не моделирует (показывается) |

Встроенные файлы лежат в корне проекта, загруженные — в `user_files/`. Каждый загруженный файл сразу проверяется. Битый файл отклоняется с указанием строки и причины, а прежняя версия файла с тем же именем восстанавливается.

**ИИ и ваши файлы.** ИИ обучен на файлах `Poltavka.CLI`, `final/Wheat/Barley.CRO`, `Poltavka_NKA.SOL` (а также Loam и SandyLoam), `final_2.MAN` и постоянном уровне грунтовых вод. Совпадение проверяется по содержимому файлов (sha256), а не по имени. Если выбран другой файл, сайт показывает только физику и объясняет почему. Чтобы ИИ работал с новыми файлами, поменяйте `DEFAULTS` и `TRAIN_CROPS` в `kucrop_core.py` и запустите `python generate_model.py`.

## Код

| Файл | Назначение |
|---|---|
| `aquacrop_files.py` | чтение форматов AquaCrop 7.x |
| `kucrop_core.py` | библиотека файлов, сборка модели, `simulate()`, применимость ИИ |
| `run_aquacrop.py` | вызывается сервером: расчёт, `--config`, `--validate`, `--inspect` |
| `server.js` | Express: `/api/config`, `/api/predict`, `/api/files` (загрузка, удаление, скачивание) |
| `generate_model.py` | обучение ИИ: `aquacrop_model.onnx`, `model_meta.json`, `training_data.csv` |
| `onnx_export.py` | экспорт в ONNX (skl2onnx или встроенный), сверка со sklearn |
| `selfcheck.py` | 14 проверок физики и совпадения ИИ с физикой |

## Проверка (AquaCrop 3.1.0)

- `Wheat.CRO` и `Barley.CRO` совпали со встроенными культурами ФАО в пакете по всем 66 параметрам. Культура в градусо-днях согласуется с вариантом в календарных днях: ячмень созревает за 96 дней против 93.
- **Подсолнечник 2024:**
  - грунтовые воды на 1.2 м: 2.78 т/га, капиллярный подъём 43 мм;
  - грунтовые воды на 10 м: 2.48 т/га;
  - без грунтовых вод: 2.48 т/га (совпадает с вариантом 10 м, как и должно быть).
- **ИИ, отложенные 20%:** R² = 0.9986, RMSE = 0.10 т/га.
  - подсолнечник: RMSE = 0.06 т/га
  - пшеница: RMSE = 0.13 т/га
  - ячмень: RMSE = 0.09 т/га

  По глубине грунтовых вод от 1 до 10 м ИИ отклоняется от физики не больше чем на 0.10 т/га.

## Исправлено по сравнению с первой версией

- Параметры культур не применялись: движок молча отбрасывал незнакомые имена.
- Грунтовые воды были выключены (`water_table='Constant'` вместо `'Y'`).
- Водный баланс, биомасса и HI были константами-заглушками, график кроны состоял из нулей, пшеница падала с ошибкой, погода 2021 года шла под видом 2024-го.
- **Начальная влажность задавалась только для верхнего горизонта.** Нижние горизонты стартовали с влажностью 0, ниже точки увядания. Это искажало расчёты с WP и без грунтовых вод. Ошибка была и в v2. Теперь влажность задаётся для каждого горизонта.

## Ограничения (важно для защиты)

1. **ИИ воспроизводит физику для 2024 года и файлов обучения.** Прогнозом урожая на другие годы он не является.
2. **`Wheat.CRO` — стандартная озимая пшеница ФАО** (Италия, 197 дней). Для яровой пшеницы СКО загрузите откалиброванный `.CRO`.
3. **Чего движок OSPy не моделирует:** плодородие 15% и сорняки из `.MAN`, засолённость из `.GWT`. Поэтому урожай может быть выше, чем в настольном AquaCrop.
4. **`Poltavka_0712.GWT`:** в заголовке написано 1.70 м, а в данных 1.90 м. Используются данные; интерфейс подсвечивает это расхождение.
5. **Старт с влажностью WP** во всём профиле — крайний сценарий: по алгоритму ФАО сухая почва не проводит капиллярный подъём, поэтому урожай близок к нулю.
